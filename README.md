## Live Market Data

Market information is retrieved from the DEX Screener API.

The website can display:

- Price
- 24H price change
- Market capitalization
- Liquidity
- 24H volume

Market data automatically refreshes periodically.

If the token has not yet been indexed by DEX Screener, unavailable values use appropriate fallback states instead of displaying fake market information.

## Development

Clone the repository:

```bash
git clone https://github.com/joaoloureiro-dev/yarl-og-rh.git
```

Enter the project:

```bash
cd yarl-og-rh
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## Production Build

Create a production build:

```bash
npm run build
```

The generated production files will be available in:

```text
dist/
```

Preview the production build locally:

```bash
npm run preview
```

## Design

The visual identity was designed specifically for Yarl OG.

The interface combines:

- Cartoon typography
- Robinhood-inspired green tones
- Yarl yellow
- Heavy illustrated borders
- Offset shadows
- Irregular containers
- Slight rotations
- Responsive motion
- Meme culture aesthetics

The design intentionally avoids a conventional corporate crypto landing-page style.
